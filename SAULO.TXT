Conversor AFND (com movimentos vazios 'h') -> AFD equivalente + teste de palavras.

Executar (na pasta onde estao entrada_1.txt e entrada_2.txt):
    python main.py

Gera na mesma pasta:
    saida_1.txt  -> AFD equivalente (mesmo formato da entrada_1)
    saida_2.txt  -> cada palavra de entrada_2.txt + TAB + aceita/rejeita

Tambem aceita caminhos: python main.py entrada_1.txt entrada_2.txt saida_1.txt saida_2.txt
